# AgriPulse 路线图

本文件是计划，不代表功能已经实现或承诺上线日期。

| 阶段 | 目标 | 完成标准 |
| --- | --- | --- |
| v0.1 · 当前 | 硬件可选的监测闭环 | 模拟、HTTP 上报、SQLite 历史、规则提示、CSV、中文看板 |
| v0.2 | 设备与协议扩展 | 可配置地块、ESP32 实测示例、MQTT 独立桥接、设备标定文档 |
| v0.3 | 可追溯管理 | 告警事件历史、阈值修改记录、导出分页、数据库迁移与备份 |
| v0.4 | Agent / MCP 只读接入 | 提供查询设备、历史、阈值解释的只读工具；鉴权与审计 |

## 优先原则

先提高数据可信度和设备接入体验，再增加 AI。AI 输出必须能够回指设备读数和规则来源；真实设备控制需要独立设计授权、硬件保护和审计。本项目当前不提供自动灌溉执行。
